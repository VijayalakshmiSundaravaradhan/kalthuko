# Kalthuko Project Goals

Learn a new language using the cues from the known language.
Every lesson should build on what the learner already knows, while preserving the history of exactly what was taught.

## User Requirements (URS)

### URS-1: Login Page
I want to sign in with my name, email, and password so that I can access my language learning experience securely and from any device.

### URS-2: Profile Setup
I want a separate profile for each language pair (e.g., Tamil → Kannada).

### URS-3: Lesson Display
I want to learn a **new** lesson everyday through my known language and I should be able to revise previous lessons
